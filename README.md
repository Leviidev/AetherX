# AetherX

**A multi-system emulator for iOS.**

---

## ⚠️ Legal Notice

**We cannot and will not host source code for AetherX on GitHub or any public platform.**

Nintendo actively issues DMCA takedown notices against repositories hosting Nintendo Switch emulator source code (as happened with Yuzu, Sudachi, and others). To protect this project and its contributors from legal action, the source code is **not publicly available**.

---

## About

AetherX is a native iOS emulation frontend supporting multiple classic gaming systems through libretro cores, with experimental Nintendo Switch support.
